# 基于 AICP 开发同类代码智能体产品

## 对标 Hermes Agent、Claude Code：底层架构、能力边界、产品形态的核心区分

---

## 前置基础：两类产品底层原生定位完全不同

### 1. Hermes / Claude Code 统一底层范式：模型单循环驱动、领域专用封闭 Runtime

**Claude Code**：核心是单 `while(true)` 模型循环，内置 40+ 固定代码工具，一切调度、工具选择、任务分支由大模型输出决定，私有 TypeScript Runtime，绑定 Claude 模型生态，仅面向代码开发场景。

**Hermes Agent**：Python 专属六层封闭运行时，内置 70+ 预制工具，依靠本地文件 + SQLite 做隔离记忆，技能仅能生成本地 Markdown 文件，多模型兼容但通信层无统一标准，同样以代码 / 本地任务为边界。

> **二者共性**：Runtime 为系统核心，工具池出厂固化，通信私有、场景锁死，多智能体协同为附加补丁功能。

### 2. AICP 构建的代码智能体：统一 Envelop 协议驱动、全域均质分布式节点

- 代码智能体只是系统内普通 Plugin 节点，和记忆服务、前端 Shell、硬件调度、业务数字员工完全平等
- 四字段 Envelop 是全局唯一通信标准，调度依靠全局统一 `route()`，无专属封闭 Runtime
- 代码能力仅为场景子集，原生支持跨设备、跨岗位、跨软硬件群体协同，工具可 AI 自主生成，不局限代码领域

---

## 八大核心维度区分

---

### 一、系统底层驱动核心（最本质鸿沟）

| 维度 | Hermes / Claude Code | AICP 代码智能体 |
|------|---------------------|-----------------|
| 核心架构 | 模型循环 + 私有 Runtime 双核心 | 全域 Envelop 消息协议为唯一核心，模型只是算力插件 |
| 调度方式 | 被单任务循环锁死，依赖 LLM 输出决策 | 任务拆分、并行、协同、记忆交互全部标准化为 intent 消息 |
| 模块通信 | 内部函数、私有事件通信，跨语言需大量胶水适配 | 无封闭单体 Runtime，靠统一消息互通 |
| 分布式 | 无原生分布式设计，协同只能叠加补丁 | 分布式、多节点并行、跨设备同步是协议原生能力 |

---

### 二、工具 / 代码能力生成机制（有无自演化分界线）

#### Hermes / Claude Code

- 静态预制工具池，AI 仅能调用，无法创造全新执行单元
- 出厂内置固定文件、Shell、Git 工具集合，工具定义写死在框架源码
- Hermes 仅能把任务提炼为本地 Markdown 技能文件，无法转化为全局可调度插件节点
- 无跨 Agent 工具共享机制，A 生成的技能无法自动同步给 B、C 智能体

#### AICP 代码智能体

- **无全局预制工具池，AI 可通过协议消息动态生成完整 Plugin**
- 代码 Agent 可发送 `plugin.create` 意图，自动生成具备独立执行能力的全新插件
- 单次项目沉淀的代码流程、专用脚本、领域工具，可自主迁移至公共协同池
- 工具、插件、技能统一为协议节点，不存在领域隔离

---

### 三、记忆与工程资产体系（单机隔离 vs 全域协同双模记忆）

#### Hermes / Claude Code

| 特性 | 说明 |
|------|------|
| 记忆范围 | 单机本地隔离记忆，无企业级全局协同底座 |
| 持久化 | 仅本地 SQLite + 文件存储，多设备间无法自动共享 |
| 资产沉淀 | 无自主记忆迁移权限，记忆是会话附属品而非组织资产 |

#### AICP 代码智能体

| 特性 | 说明 |
|------|------|
| 记忆架构 | 内嵌商用向量检索引擎的全域双模统一记忆插件 |
| 分层设计 | 短期会话上下文随 Envelop 消息流转，长期存入统一记忆节点 |
| 三级隔离 | 个人私有草稿 → 项目分组共享库 → 企业全员公共代码知识库 |
| 同步能力 | 公共记忆写入后协议自动广播同步，全链路操作消息留痕审计 |

---

### 四、多智能体 / 多人协同能力（附加补丁 vs 原生底层能力）

#### Hermes / Claude Code

- 协同是上层附加功能，架构底层**不支持**分布式网络
- Claude Code 仅支持单次任务内临时子 Agent，任务销毁后全部销毁
- 多实例通信依赖私有桥接服务，存在同步延迟
- 多人开发场景无统一工程资产池，经验无法互通

#### AICP 代码智能体

- **群体协同是协议底层原生设计**
- 所有节点依靠 Envelop 广播实现实时数据、记忆同步
- 串行开发流水线、并行多模块开发、跨岗位协同依靠路由自然涌现
- 新增开发节点零适配接入协同网络

---

### 五、场景边界：单一代码专用 vs 全域通用底座

| 对比项 | Hermes / Claude Code | AICP 代码智能体 |
|--------|---------------------|-----------------|
| 场景范围 | 仅限代码开发单一场景 | 代码、硬件、业务数字员工全域通用 |
| 扩展成本 | 跨领域需从零重构整套框架 | 一套底座覆盖多场景 |
| 交互入口 | 仅限 CLI、IDE 插件、本地 Web TUI | 可对接工业硬件、嵌入式终端、企业业务系统 |

---

### 六、模型绑定与自主可控性

| 对比项 | Hermes / Claude Code | AICP 代码智能体 |
|--------|---------------------|-----------------|
| 模型耦合 | 深度绑定 Claude 系列模型，底层闭源 | 任意开源/闭源大模型统一封装为标准 Plugin 节点 |
| 组件替换 | 更换存储/调度组件需大规模重构 | 替换模型、切换向量检索引擎上层无感知 |
| 私有化 | 无法完全私有化、国产化改造 | 底层协议全自研，可完整剥离第三方商用组件 |

---

### 七、跨平台、跨语言互通成本

#### Hermes / Claude Code

- 私有内部接口，异构适配成本极高
- TypeScript/Python 单体程序，跨语言需单独开发序列化、格式转换适配层
- 嵌入式、边缘设备难以部署重型 Runtime
- 多终端数据互通依赖私有 Bridge 桥接服务

#### AICP 代码智能体

- **统一 Envelop 消息抹平所有异构壁垒**
- 仅四字段标准化消息，任意编程语言、操作系统、硬件终端均可序列化传输
- 双部署模式：
  - 完整集群模式（内置向量检索，企业研发中台）
  - 轻量插件模式（仅本地文件，单机 IDE）

---

### 八、企业级落地适配能力

| 对比项 | Hermes / Claude Code | AICP 代码智能体 |
|--------|---------------------|-----------------|
| 目标用户 | 个人 / 小型开发团队 | 企业集团研发中台 |
| 多租户 | 缺少原生多租户能力 | 统一 memory 插件内置 RBAC 权限校验 |
| 审计合规 | 无全链路审计 | 每条操作留存完整 Envelop 消息日志，满足等保审计 |
| 资产沉淀 | 记忆分散，无企业统一知识库 | 全局公共代码资产池沉淀组织经验 |
| 扩展能力 | 大规模协同场景架构瓶颈明显 | 支持千级分布式开发 Agent 集群弹性扩容 |

---

## 直观对比总表

| 对比维度 | Hermes / Claude Code | 基于 AICP 构建的代码智能体 |
|----------|:--------------------:|:------------------------:|
| **底层核心** | 私有单体 Runtime + 模型单循环 | 全域 Envelop 协议，模型为普通算力插件 |
| **工具能力** | 出厂预制固定工具，无法生成新执行单元 | AI 可动态生成全新 Plugin，全集群共享 |
| **记忆体系** | 单机本地隔离，无全局协同资产池 | 双模分层全域记忆，公私隔离 + 企业公共库 |
| **多 Agent 协同** | 单次任务临时子 Agent，多机协同需额外同步服务 | 原生分布式节点网络，并行/跨团队协同底层原生 |
| **场景范围** | 仅限代码开发，跨领域需重构 | 代码、硬件、业务数字员工全域通用 |
| **跨语言跨平台** | 私有接口，异构适配胶水代码量大 | 统一消息天然互通，任意终端零适配接入 |
| **自主可控** | Runtime 封闭，厂商锁定 | 协议全自研，完全私有化部署 |
| **企业适配** | 个人小团队工具，缺少审计/全局资产能力 | 原生支持集团级研发中台、权限隔离、合规审计 |

---

## 总结：两类产品本质层级差异

**Hermes、Claude Code** 属于垂直领域上层应用工具，解决单人 / 小团队代码编写效率，底层架构设计围绕「代码单机任务」构建，协同、资产沉淀、跨域能力都是附加补丁。

**基于 AICP 开发的同类代码产品**，是企业全域 AI 底层底座之上的垂直代码能力模块：

- 不仅拥有同等代码生成、调试、工程执行能力
- 更从底层解决了行业产品固有的**单机隔离、无法群体协同、无组织资产沉淀、跨平台适配成本高**的结构性短板

> **二者不存在简单的功能替代关系，而是上层工具与底层通用分布式智能体操作系统的维度差距。**
